# Licensing Decision

## Selected license: MIT

The selected policy has three parts: commercial use must be allowed, users may keep their
applications closed source, and attribution is appreciated but not mandatory. The MIT License
matches this scope:

- commercial use, modification, and distribution are allowed;
- applications using Nandina may remain proprietary;
- copyright and license notices must be retained in copies or substantial portions of the Software.

The MIT License does not require a product to display a marketing attribution notice. A project
`NOTICE` or About-page attribution is welcome as a separate convention, but it is not a condition
of use.

The root `LICENSE` file records the selected MIT text and copyright holder. The release metadata
marks the license as confirmed, and the metadata test verifies that the file is present.
